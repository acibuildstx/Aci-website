# V2 gallery photo mapping

Sources are the chosen photographs in the numbered ACI Google Drive folder roots. The display order and cover choices below are for review. Each cover uses the same source as position 01. Replace a numbered WebP at the same path to update that gallery position. Replace the separate cover file when the cover should change. The kitchen cover also supplies the homepage hero. Drive originals were preserved.

Before & After is hidden pending approval of the tentative pairs. Custom Installations and Exterior & Siding have no verified selections. The electrical-panel file marked CANDIDATE, extra-folder photos, misplaced images, and duplicate or near-duplicate views were left out. The covered deck framework is the Patio selection.
